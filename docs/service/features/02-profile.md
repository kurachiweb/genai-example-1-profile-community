# 機能仕様 — Profile（プロフィール編集）

エンティティ **Profile** のフィールド（アイコン・氏名・職業・自己紹介・SNS リンク）の編集に関するビジネスルールと受け入れ条件を定義する。
公開・共有（ハンドル名・公開/非公開・公開ページ）は [03-profile-sharing.md](./03-profile-sharing.md)、閲覧・検索は [04-profile-discovery.md](./04-profile-discovery.md) を参照。

> 横断前提は [00-common-rules.md](./00-common-rules.md)。対応エピック: EP-02。NSFW 判定のライフサイクル詳細は [06-trust-and-safety.md](./06-trust-and-safety.md)。

## 1. エンティティ定義

Profile は User に 1:1 で紐づき、アカウント作成時に空の状態で生成される（公開フラグの既定は `public`、`BR-COMMON-006`）。

| 属性 | 型 | 必須 | 制約（正本: 本書の各 BR） |
| --- | --- | --- | --- |
| iconImage | 画像 | 任意 | `BR-PROF-001`（未設定時は既定アイコン） |
| firstName | 文字列 | 必須 | `BR-PROF-002` |
| middleName | 文字列 | 任意 | `BR-PROF-002` |
| lastName | 文字列 | 必須 | `BR-PROF-002` |
| nameDisplayOrder | 列挙 | 必須（既定あり） | `BR-PROF-004` |
| occupation | 文字列 | 任意 | `BR-PROF-005` |
| bio | テキスト | 任意 | `BR-PROF-006` |
| snsLinks | SnsLink[] | 任意 | `BR-PROF-007`（0〜10 件） |
| handle / visibility | — | — | [03-profile-sharing.md](./03-profile-sharing.md) |

> **必須項目と公開の関係**: 公開フラグは既定で `public` だが、`firstName` と `lastName` が未入力のプロフィールは公開ページに「名前未設定」として表示されうる。最小限の体裁を保つため、公開導線では必須項目の充足を促す（[03-profile-sharing.md](./03-profile-sharing.md) `BR-SHARE-005`）。

## 2. ビジネスルール

### BR-PROF-001 アイコン画像

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 対応形式 | PNG / JPEG / WebP | 主要なブラウザ・カメラ出力を網羅。SVG はスクリプト混入リスクのため不可。 |
| 最大ファイルサイズ | 5 MB | アイコン用途として十分かつアップロード負荷を抑える一般的上限。 |
| 最小寸法 | 200 × 200 px | 表示時の劣化を防ぐ最低解像度。 |
| 保存形式 | 正方形にトリミングし最大 512 × 512 へ正規化 | 一覧・OGP で破綻しない統一表示。配信は Cloudflare Images。 |
| NSFW 判定 | アップロード時に自動判定し、不適切なら**拒否** | `BR-SAFE-001`（[06-trust-and-safety.md](./06-trust-and-safety.md)）。 |
| 既定アイコン | 未設定時は自動生成のプレースホルダ | 「デフォルトで完成する」原則（コンセプト）。 |

- アップロード時にクライアント・サーバー双方で形式・サイズ・寸法を検証する（`BR-COMMON-008`）。
- 画像のメタデータ（EXIF の位置情報等）は保存前に除去する。
  - 根拠: 位置情報など意図しない個人情報の流出防止。
- 変更時は旧画像を差し替える。削除も可能（既定アイコンに戻る）。

### BR-PROF-002 氏名（ファースト/ミドル/ラスト）

| フィールド | 必須 | 最大長（書記素） | 備考 |
| --- | --- | --- | --- |
| firstName | 必須 | 50 | 1 文字以上 |
| middleName | 任意 | 50 | ミドルネーム・複数ミドルを許容 |
| lastName | 必須 | 50 | 1 文字以上 |

- 文字種は Unicode の文字・空白・ハイフン（`-`）・アポストロフィ（`'`）・中黒（`・`）・ピリオド（`.`）を許容する。`BR-COMMON-009` の正規化・不可視文字除去を適用する。
  - 根拠: 「David Cruz-Tanaka」のような複合姓や、日本語名・海外名を崩さず扱う（コンセプト「名前に敬意を払う」）。
- 各フィールドに改行・制御文字は不可。
- **単一名（mononym）への対応**: v1 は firstName・lastName を必須とする。単一名のみのユーザーは将来課題とし、本書の改訂で対応する（オープン事項、`§5`）。

### BR-PROF-003 表示名の組み立て

- 表示名は `firstName` / `middleName` / `lastName` と `nameDisplayOrder` から決定論的に組み立てる。ミドルネームが空の場合は前後の余分な空白を生じさせない。
- 表示名は検索・一覧・OGP・公開ページで一貫して用いる（[04-profile-discovery.md](./04-profile-discovery.md)）。

### BR-PROF-004 名前の表示順

- `nameDisplayOrder` は次の 2 値: `givenNameFirst`（名→姓、例: みなと 里中 / David Cruz-Tanaka）、`familyNameFirst`（姓→名、例: 里中 みなと）。
- 既定値は `givenNameFirst`。
  - 根拠: 多くの SNS・国際的文脈の既定に合わせつつ、日本語話者向けに姓→名へ切り替え可能とし、名前を尊重する。

### BR-PROF-005 職業・職種

| 項目 | 値 |
| --- | --- |
| 最大長（書記素） | 50 |
| 必須 | 任意（推奨） |
| 形式 | 単一行・改行不可 |

- 根拠: 肩書きは一目で伝わる短さが要。50 文字で「フリーランス イラストレーター」等を十分表現できる。

### BR-PROF-006 自己紹介文（bio）

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 最大長（書記素） | 500 | 肩書きを補足する範囲。長文プロフィールは「手軽さ」の核から外れる。 |
| 形式 | プレーンテキスト（HTML 不可）・改行可 | XSS 防止（`BR-PROF-008`）。 |
| URL の扱い | 表示時に自動リンク化（サニタイズ後） | 利便性と安全性の両立。 |

### BR-PROF-007 SNS / Web リンク（SnsLink）

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 最大件数 | 10 | リンク集約の用途に十分。多すぎると一覧性を損なう。 |
| 種別（platform） | `x` / `github` / `linkedin` / `instagram` / `youtube` / `facebook` / `tiktok` / `website`（その他） | README・ペルソナに登場する主要サービス＋汎用 Web。 |
| URL | `https://` のみ・最大 2048 文字 | 平文 HTTP を排除。URL 長は実用上限。 |
| 表示順 | 利用者が並べ替え可能 | 見せたい順に提示できる。 |
| ラベル | 任意・最大 30 文字 | `website`（その他）に表示名を付与可能。 |

- 各 URL は形式検証を行う。種別が既知サービスの場合、当該サービスのホストに属することを推奨検証する（厳格すぎる拒否は避け、`website` での登録を許容）。
- 同一 URL の重複登録は警告するが拒否はしない（同一サービスの別アカウント等を許容）。
- リンクは公開ページで `rel="nofollow noopener noreferrer"`、別タブ遷移とする。
  - 根拠: 被リンク悪用・タブナビング・リファラ漏えいの防止。

### BR-PROF-008 入力の無害化（XSS 防止）

- すべてのテキスト入力は HTML を許可せず、表示時にエスケープする。`dangerouslySetInnerHTML` 等の生 HTML 挿入は行わない（[.claude/rules/ecc-web/security.md](../../../.claude/rules/ecc-web/security.md)）。
- 自動リンク化はサニタイズ済み URL のみを対象とし、`javascript:` 等の危険スキームを除外する。

### BR-PROF-009 ライブプレビュー（Could）

- 編集中に公開ページの完成イメージをプレビュー表示できる（US-0206）。プレビューは保存前の入力値を反映し、保存しなければ確定しない。

### BR-PROF-010 保存と即時反映

- 各フィールドは個別または一括で保存できる。保存はバリデーション通過後にのみ確定し、成功時は即時に表示へ反映する。
- 保存失敗時は入力値を失わせず、フィールド単位のエラーを提示する（`BR-COMMON-012`）。

## 3. 受け入れ条件（Given/When/Then）

### アイコン画像

#### AC-PROF-001 アイコン保存（正常系）

- **関連ストーリー**: US-0201
- **Given**: ログイン中の利用者がプロフィール編集画面にいる
- **When**: 5 MB 以下・200×200 px 以上の PNG を選択して保存する
- **Then**: NSFW 判定を通過した画像が正方形 512px へ正規化・EXIF 除去のうえ保存され、即時にプレビューへ反映される

#### AC-PROF-002 サイズ超過の拒否（境界値）

- **関連ストーリー**: US-0201
- **Given**: プロフィール編集画面にいる
- **When**: 5 MB を超える画像を選択する
- **Then**: 「5 MB 以下の画像を選択してください」と表示され、保存されない

#### AC-PROF-003 非対応形式の拒否（異常系）

- **関連ストーリー**: US-0201
- **Given**: プロフィール編集画面にいる
- **When**: SVG または GIF など非対応形式をアップロードする
- **Then**: 対応形式（PNG/JPEG/WebP）を案内するエラーが表示され、保存されない

#### AC-PROF-004 NSFW 画像の拒否（異常系）

- **関連ストーリー**: US-0201 / US-0601
- **Given**: プロフィール編集画面にいる
- **When**: NSFW と判定される画像をアップロードする
- **Then**: アップロードが拒否され、既存アイコンは変更されず、判定結果が記録される（[06-trust-and-safety.md](./06-trust-and-safety.md) `BR-SAFE-001`）

#### AC-PROF-005 アイコン削除で既定に戻る（正常系）

- **関連ストーリー**: US-0201
- **Given**: アイコンを設定済みの利用者
- **When**: アイコンを削除する
- **Then**: 自動生成の既定アイコンが表示される

### 氏名

#### AC-PROF-006 ミドルネーム込みの登録（正常系）

- **関連ストーリー**: US-0202
- **Given**: プロフィール編集画面にいる
- **When**: First=「David」, Middle=「Cruz」, Last=「Tanaka」を保存する
- **Then**: 表示名が崩れず「David Cruz Tanaka」（`givenNameFirst`）として一貫表示される

#### AC-PROF-007 ミドルネーム空欄でも余分な空白なし（境界値）

- **関連ストーリー**: US-0202
- **Given**: プロフィール編集画面にいる
- **When**: First=「みなと」, Middle=空, Last=「里中」を保存する
- **Then**: 表示名に二重空白が生じず、`familyNameFirst` 設定時は「里中 みなと」と表示される

#### AC-PROF-008 必須氏名の欠落（異常系）

- **関連ストーリー**: US-0202
- **Given**: プロフィール編集画面にいる
- **When**: First または Last を空のまま保存する
- **Then**: 必須である旨のフィールドエラーが表示され、保存されない

#### AC-PROF-009 表示順の切り替え（正常系）

- **関連ストーリー**: US-0202
- **Given**: 氏名を登録済みの利用者
- **When**: 表示順を `familyNameFirst` に切り替える
- **Then**: 公開ページ・一覧・検索すべてで姓→名の順に統一表示される

### 職業・自己紹介

#### AC-PROF-010 職業の登録（正常系）

- **関連ストーリー**: US-0203
- **Given**: プロフィール編集画面にいる
- **When**: 職業に「フリーランス イラストレーター」を入力して保存する
- **Then**: 公開ページの肩書きとして表示される

#### AC-PROF-011 自己紹介の文字数上限（境界値）

- **関連ストーリー**: US-0204
- **Given**: プロフィール編集画面にいる
- **When**: 501 文字（書記素）の自己紹介を保存しようとする
- **Then**: 上限超過のエラーが表示され、保存されない。500 文字ちょうどは保存できる

#### AC-PROF-012 自己紹介の HTML 無害化（異常系・セキュリティ）

- **関連ストーリー**: US-0204
- **Given**: プロフィール編集画面にいる
- **When**: 自己紹介に `<script>` や HTML タグを含めて保存する
- **Then**: スクリプトは実行されず、文字としてエスケープ表示される

### SNS リンク

#### AC-PROF-013 SNS リンクの登録と遷移属性（正常系）

- **関連ストーリー**: US-0205
- **Given**: プロフィール編集画面にいる
- **When**: 種別 `github` と `https://github.com/example` を登録する
- **Then**: リンクが保存され、公開ページで別タブ・`rel="nofollow noopener noreferrer"` 付きで表示される

#### AC-PROF-014 非 HTTPS / 危険スキームの拒否（異常系）

- **関連ストーリー**: US-0205
- **Given**: プロフィール編集画面にいる
- **When**: `http://…` または `javascript:…` を URL として登録する
- **Then**: `https://` のみ許可である旨のエラーが表示され、保存されない

#### AC-PROF-015 リンク件数上限（境界値）

- **関連ストーリー**: US-0205
- **Given**: 既に 10 件の SNS リンクを登録済み
- **When**: 11 件目を追加しようとする
- **Then**: 上限（10 件）に達している旨が表示され、追加されない

#### AC-PROF-016 リンクの並べ替え（正常系）

- **関連ストーリー**: US-0205
- **Given**: 複数の SNS リンクを登録済み
- **When**: 表示順を入れ替えて保存する
- **Then**: 公開ページに保存した順序で表示される

### プレビュー

#### AC-PROF-017 ライブプレビュー（正常系・Could）

- **関連ストーリー**: US-0206
- **Given**: プロフィール編集画面にいる
- **When**: 各項目を入力する
- **Then**: 保存前でも公開ページの完成イメージがプレビューに反映され、保存しなければ確定しない

## 5. オープン事項（要追記・将来課題）

- **単一名（mononym）対応**: 現状 First/Last 必須。単一名のみのユーザー対応は将来課題（`BR-PROF-002`）。
- **アイコンの代替テキスト**: アクセシビリティ向けに `alt` を表示名から自動生成する想定。詳細はデザインシステム/アクセシビリティガイドで確定する。
