# 機能仕様 — Profile（閲覧・検索）

閲覧者（多くは未ログイン）が公開プロフィールを閲覧・一覧・検索する機能のビジネスルールと受け入れ条件を定義する。

> 横断前提は [00-common-rules.md](./00-common-rules.md)。対応エピック: EP-04。
> 公開ページの表示・非公開時の秘匿は [03-profile-sharing.md](./03-profile-sharing.md) を正本とする。本書は閲覧者体験（一覧・検索・遷移）を扱う。

## 1. 概要

閲覧者は会員登録・ログインなしで、実効公開（`BR-COMMON-007`）のプロフィールを閲覧でき、一覧・検索から目的の人物を見つけられる（コンセプト「見るのが速い」）。

## 2. ビジネスルール

### BR-DISC-001 露出対象（実効公開のみ）

- 一覧・検索・公開ページに露出するのは **実効公開のプロフィールのみ**（`effectivePublic()` が真）。
- 非公開・メール未確認・凍結・退会のプロフィールは、一覧・検索結果・サジェスト・サイトマップのいずれにも現れない。
  - 根拠: 状態の秘匿（`BR-SHARE-006`/`BR-SHARE-010`）と一貫させる。

### BR-DISC-002 閲覧（ログイン不要）

- 公開ページはログイン不要で閲覧できる（US-0401）。閲覧自体に個人情報の入力を求めない。
- SNS リンクは別タブ・`rel="nofollow noopener noreferrer"` で遷移する（US-0402、`BR-PROF-007`）。

### BR-DISC-003 一覧

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 表示単位 | 1 ページ 20 件 | 一覧性とスクロール負荷の均衡。 |
| 並び順（既定） | 新着・更新日時の新しい順 | 活動中のプロフィールを発見しやすい。 |
| ページング | カーソルベース（公開 API と整合、[05-public-api.md](./05-public-api.md)） | 大量データでも安定。重複/欠落を避ける。 |
| 表示項目 | アイコン・表示名・職業（肩書き） | 一覧で素早く判断できる最小情報。 |

### BR-DISC-004 検索

- 検索対象フィールドは **表示名（氏名）**・**職業**・**自己紹介（bio、`BR-PROF-006`）** とする（US-0404）。
- 検索は部分一致・大文字小文字非依存。日本語は表記揺れに配慮し、可能な範囲で正規化（`BR-COMMON-009`）して比較する。
- クエリ最大長は 100 文字。空クエリは一覧（`BR-DISC-003`）と同等に扱う。
- 並び順は「関連度」または「新着」を選択でき、既定は関連度。関連度はフィールド優先度を **氏名一致 ＞ 職業一致 ＞ 自己紹介一致** とする（自己紹介は補足情報のため最下位、簡易ヒューリスティックの詳細は [ADR 20260603](../../adr/20260603-profile-search-fts5.md)）。
- 検索結果はページング（`BR-DISC-003` と同条件）に従う。

### BR-DISC-005 濫用対策（スクレイピング抑制）

- 未認証の閲覧・検索・一覧は IP 単位のレート制限（60 リクエスト / 分、`BR-COMMON-010`）の対象とする。
- 一覧・検索からの大量取得を抑止するため、ページング上限（最大 100 件/リクエスト）と総ページ深度の上限を設ける。

### BR-DISC-006 結果の鮮度・整合

- 公開→非公開、凍結、退会、ハンドル変更の反映は、一覧・検索結果に**速やかに**反映する（キャッシュは短 TTL）。
  - 根拠: 非公開化したプロフィールが検索に残り続ける事態を避ける（秘匿の整合）。

### BR-DISC-007 アクセシビリティ

- 一覧・検索 UI はキーボード操作・スクリーンリーダーに対応し、各プロフィールカードは表示名を主見出しとする（詳細は `docs/GUIDES/design-system/`・アクセシビリティガイド）。

## 3. 受け入れ条件（Given/When/Then）

### 閲覧

#### AC-DISC-001 ログイン不要の閲覧（正常系）

- **関連ストーリー**: US-0401
- **Given**: 実効公開のプロフィールが存在する
- **When**: 未ログインの閲覧者が共有された固有 URL を開く
- **Then**: ログインを求められず、プロフィールが表示される

#### AC-DISC-002 SNS リンクへの遷移（正常系）

- **関連ストーリー**: US-0402
- **Given**: SNS リンクを持つ公開プロフィールを閲覧している
- **When**: SNS リンクを押す
- **Then**: 別タブで対象 URL に遷移し、`rel="noopener noreferrer"` によりリファラ等が保護される

### 一覧

#### AC-DISC-003 公開プロフィール一覧（正常系）

- **関連ストーリー**: US-0403
- **Given**: 複数の実効公開プロフィールが存在する
- **When**: 閲覧者が一覧ページを開く
- **Then**: 1 ページ 20 件、新着順でアイコン・表示名・職業が表示され、次ページへ辿れる

#### AC-DISC-004 非公開は一覧に出ない（整合）

- **関連ストーリー**: US-0403 / US-0302
- **Given**: 非公開・未確認・凍結・退会のプロフィールが存在する
- **When**: 閲覧者が一覧を開く
- **Then**: それらは一覧に一切表示されない

### 検索

#### AC-DISC-005 名前での検索（正常系）

- **関連ストーリー**: US-0404
- **Given**: 表示名に「里中」を含む公開プロフィールが存在する
- **When**: 検索語「里中」で検索する
- **Then**: 該当する公開プロフィールが結果に表示される

#### AC-DISC-006 職業での絞り込み（正常系）

- **関連ストーリー**: US-0404
- **Given**: 職業に「イラストレーター」を含む公開プロフィールが存在する
- **When**: 検索語「イラストレーター」で検索する
- **Then**: 該当する公開プロフィールが結果に表示される

#### AC-DISC-007 自己紹介での検索（正常系）

- **関連ストーリー**: US-0404
- **Given**: 自己紹介（bio）に「水彩」を含む公開プロフィールが存在する（表示名・職業には含まれない）
- **When**: 検索語「水彩」で検索する
- **Then**: 該当する公開プロフィールが結果に表示される。氏名・職業一致のプロフィールがある場合、それらより下位に並ぶ

#### AC-DISC-008 該当なし（境界値）

- **関連ストーリー**: US-0404
- **Given**: どのプロフィールにも一致しない検索語
- **When**: その語で検索する
- **Then**: 「該当する結果がありません」と表示され、エラーにはならない

#### AC-DISC-009 非公開化の即時反映（整合）

- **関連ストーリー**: US-0404 / US-0302
- **Given**: 検索結果に出ていたユーザーが非公開に切り替えた
- **When**: 同じ検索語で再検索する
- **Then**: そのユーザーは結果に表示されない

#### AC-DISC-010 検索のレート制限（境界値）

- **関連ストーリー**: US-0404
- **Given**: 同一 IP から短時間に大量の検索/一覧リクエストが行われている
- **When**: しきい値（60 リクエスト/分）を超える
- **Then**: 一時的に制限され、再試行までの案内が返る
