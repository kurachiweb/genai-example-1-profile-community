# 機能仕様 — AdminAccount / 管理者コンソール

エンティティ **AdminAccount** と、管理者コンソールにおけるガバナンス機能（管理者アカウント/権限・ユーザー管理・モデレーション操作・API キー運用・利用統計・監査ログ）のビジネスルールと受け入れ条件を定義する。

> 横断前提は [00-common-rules.md](./00-common-rules.md)。対応エピック: EP-07（US-0701/0702/0703/0704/0706/0707/0708）。
> 通報・凍結・解除リクエストのライフサイクルは [06-trust-and-safety.md](./06-trust-and-safety.md)、お知らせ・通知・ヘルプ・規約は [08-content-and-comms.md](./08-content-and-comms.md) を正本とする。本書はそれらに対する**管理者操作**と権限を定義する。

## 1. 概要

管理者コンソール（admin 側 Next.js アプリ）は運営チームが利用する。利用者アプリ（client）とは別アプリ・別セッションで分離する（`BR-COMMON-002`）。
すべての管理者操作は監査ログに記録し（`BR-COMMON-013`）、ロールベースアクセス制御（RBAC）で権限を制御する。

## 2. 管理者アカウントと権限（RBAC）

### BR-ADMIN-001 管理者アカウント

- 管理者アカウントは利用者アカウントとは別のエンティティ・別ストアで管理する。
- 認証は HTTPS-Only Cookie セッション（有効 8 時間・アイドル 30 分、`BR-COMMON-002`）。MFA を推奨。
- 管理者の作成は、既存のスーパー管理者（`BR-ADMIN-002`）のみが行える。初期スーパー管理者はプロビジョニング手順で作成する（画面からの自己昇格は不可）。

### BR-ADMIN-002 ロールと権限マトリクス

| ロール | 説明 | 主な権限 |
| --- | --- | --- |
| `super_admin` | 最上位管理者 | 全権限。管理者アカウント・権限の管理、API しきい値変更、規約公開を含む。 |
| `moderator` | モデレーター | ユーザー管理（凍結/解除/アイコン削除）、通報・解除リクエスト処理。 |
| `support` | サポート | 問い合わせ対応、ヘルプ記事編集、お知らせ下書き。ユーザー処分は不可。 |
| `viewer` | 閲覧のみ | 統計・監査ログ・各種一覧の閲覧のみ。変更操作は不可。 |

- 権限は**最小権限の原則**に従う。各操作は対応する権限を要求し、権限のない操作は UI から不可かつ API でも `403`。
- ロール変更・管理者の追加/削除は `super_admin` のみが行え、監査ログに記録する（US-0706）。
- 自分自身の権限の剥奪・最後のスーパー管理者の削除は防止する（ロックアウト防止）。

### BR-ADMIN-003 管理者操作の共通ルール

- すべての変更操作（凍結・削除・権限変更・しきい値変更・規約公開 等）は、操作者・対象・日時・理由（必要なもの）を監査ログに記録する。
- 影響の大きい操作（凍結・規約公開・しきい値変更・管理者削除）には確認ステップを設ける。

## 3. ユーザー管理・モデレーション

### BR-ADMIN-004 ユーザー一覧・詳細

- 管理者はユーザーを一覧・検索（メール・ハンドル・状態でフィルタ）し、詳細（状態・登録日・公開状態・通報件数・API キー数など）を閲覧できる（US-0701）。
- 一覧・詳細での個人データ表示は職務上必要な範囲に限り、表示自体も監査の対象とする（重要操作時）。

### BR-ADMIN-005 モデレーション操作

- 管理者（`moderator` 以上）は次を行える:
  - アイコン削除（不適切画像、US-0702 / [06](./06-trust-and-safety.md) `BR-SAFE-002`）。
  - ユーザー凍結（US-0703 / `BR-SAFE-006`）。
  - 通報の審査・処分（`BR-SAFE-005`）。
- これらの効果・状態遷移は [06-trust-and-safety.md](./06-trust-and-safety.md) を正本とし、本書はそれを管理者が実行する操作として扱う。

### BR-ADMIN-006 解除リクエストの審査

- 管理者（`moderator` 以上）は解除リクエストを審査し、承認（解除）・却下できる（US-0704 / `BR-SAFE-008`）。
- 承認/却下は監査ログに記録し、ユーザーの状態を整合的に更新する。

## 4. 公開 API キー運用・レート制限

### BR-ADMIN-007 API キーの運用監視

- 管理者は発行済み API キーの**メタ情報のみ**（所有ユーザー・ラベル・作成日・最終利用日・状態）を閲覧できる。**キーの秘匿値は閲覧不可**（`BR-API-001`）。
- 濫用が疑われるキーを失効できる（US-0707）。失効は監査ログに記録し、所有ユーザーに影響する。

### BR-ADMIN-008 共通レート制限しきい値の変更

- 管理者（`super_admin`）は、公開 API の**全キー共通のレート制限しきい値**（既定 60 リクエスト/分、`BR-API-008`）を変更できる（US-0707）。
- アプリ層（@nestjs/throttler）の値は管理画面から変更し、本番のエッジ（Cloudflare WAF）閾値は Terraform で管理する（[CLAUDE.md](../../../CLAUDE.md) デプロイ方針）。両者は整合させる運用とする。
- しきい値変更は監査ログに記録する。

## 5. 利用統計・監査ログ

### BR-ADMIN-009 利用統計

- 管理者は利用統計を閲覧できる（US-0708）。指標例: 登録数・実効公開プロフィール数・アクティブ数・通報件数・凍結件数・API リクエスト量。
- 統計は集計値であり、不要な個人特定を伴わない形で提示する。

### BR-ADMIN-010 監査ログ（AuditLog）

- `AuditLog` は**追記専用・改ざん不可**（更新/削除不可）とする。`BR-COMMON-013` の対象イベントを記録する。
- 記録項目: イベント種別・操作者（管理者/ユーザー/システム）・対象・日時（UTC 保存）・結果・関連メタ（理由・旧新値の差分など）。秘匿値は記録しない（`BR-COMMON-014`）。
- 管理者は監査ログを**閲覧・絞り込み**できる（US-0708）。閲覧自体も記録対象とするかは運用方針に従う。
- 保持期間は運用ポリシーに従い、退会ユーザー分も匿名化のうえ必要範囲で保持する（`BR-ACCT-009`）。

## 6. 受け入れ条件（Given/When/Then）

### 権限・管理者アカウント

#### AC-ADMIN-001 権限外操作の拒否（正常系・セキュリティ）

- **関連ストーリー**: US-0706
- **Given**: `viewer` ロールの管理者がログインしている
- **When**: ユーザー凍結など変更操作を試みる
- **Then**: 操作 UI は無効化され、API でも `403` が返り、データは変更されない

#### AC-ADMIN-002 管理者の追加はスーパー管理者のみ（正常系）

- **関連ストーリー**: US-0706
- **Given**: `super_admin` がログインしている
- **When**: 新しい `moderator` を追加する
- **Then**: 管理者アカウントが作成され、操作が監査ログに記録される

#### AC-ADMIN-003 最後のスーパー管理者の保護（境界値）

- **関連ストーリー**: US-0706
- **Given**: スーパー管理者が 1 名のみ
- **When**: その唯一のスーパー管理者を削除/降格しようとする
- **Then**: ロックアウト防止のため操作が拒否される

### ユーザー管理・モデレーション

#### AC-ADMIN-004 ユーザー一覧の閲覧・検索（正常系）

- **関連ストーリー**: US-0701
- **Given**: `moderator` 以上の管理者
- **When**: 状態 `FROZEN` でユーザー一覧を絞り込む
- **Then**: 凍結中ユーザーの一覧が表示され、詳細を開ける

#### AC-ADMIN-005 不適切アイコンの削除（正常系）

- **関連ストーリー**: US-0702
- **Given**: 不適切なアイコンを持つユーザーがいる
- **When**: 管理者がアイコンを削除する
- **Then**: アイコンが既定に戻り、削除が監査ログに記録される

#### AC-ADMIN-006 ユーザー凍結（正常系・整合）

- **関連ストーリー**: US-0703
- **Given**: 違反が認められたユーザーがいる
- **When**: 管理者が確認ステップを経て凍結する
- **Then**: 状態が `FROZEN` になり公開停止し（[06](./06-trust-and-safety.md) `BR-SAFE-006`）、監査ログに記録される

#### AC-ADMIN-007 解除リクエストの承認（正常系・整合）

- **関連ストーリー**: US-0704
- **Given**: `PENDING` の解除リクエストがある
- **When**: 管理者が承認する
- **Then**: ユーザーが `ACTIVE` に戻り、凍結前の公開設定で復帰し、監査ログに記録される

### API キー運用

#### AC-ADMIN-008 キー秘匿値は閲覧不可（正常系・セキュリティ）

- **関連ストーリー**: US-0707
- **Given**: 管理者が API キー運用画面を開いている
- **When**: あるキーの詳細を表示する
- **Then**: 所有者・ラベル・作成日・最終利用日・状態は見えるが、キーの秘匿値は表示されない

#### AC-ADMIN-009 共通しきい値の変更（正常系）

- **関連ストーリー**: US-0707
- **Given**: `super_admin` がログインしている
- **When**: 公開 API の共通レート制限を 60 → 120 リクエスト/分に変更する
- **Then**: アプリ層に反映され、変更が監査ログに記録される（本番エッジ値は Terraform で整合させる）

### 統計・監査ログ

#### AC-ADMIN-010 利用統計の閲覧（正常系）

- **関連ストーリー**: US-0708
- **Given**: `viewer` 以上の管理者
- **When**: 統計ダッシュボードを開く
- **Then**: 登録数・公開数・通報件数などの集計指標が表示される

#### AC-ADMIN-011 監査ログは追記専用（正常系・セキュリティ）

- **関連ストーリー**: US-0708
- **Given**: 監査ログにレコードが存在する
- **When**: 管理者が任意のレコードの編集/削除を試みる
- **Then**: 監査ログは変更不可であり、編集/削除手段が提供されない

#### AC-ADMIN-012 重要操作が監査に残る（正常系）

- **関連ストーリー**: US-0708
- **Given**: 管理者が凍結・アイコン削除・しきい値変更などを行った
- **When**: 監査ログを参照する
- **Then**: 操作者・対象・日時・結果が記録されており、追跡できる
