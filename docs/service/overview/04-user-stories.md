# ユーザーストーリー — GenAI Profile Community

> サービス概要は [01-overview.md](./01-overview.md)、ターゲットとペルソナは [03-target-users.md](./03-target-users.md) を参照。
> 本ドキュメントは利用者・閲覧者・管理者の「〜したい」を、機能群（エピック）別に整理する。

## このドキュメントの読み方

### 記法

各ストーリーは次の形式で記述する。

> **［ロール］として、［目的・実現したいこと］したい。なぜなら［理由・価値］だから。**

### 登場ロール

| ロール | 説明 | 代表ペルソナ |
| --- | --- | --- |
| 利用者 | プロフィールを作成・公開するユーザー | 里中、小田原、佐藤 |
| 閲覧者 | プロフィールを見る側（多くは未ログイン） | 山田 |
| 開発者 | 公開 API でプロフィールを扱うユーザー | 佐藤 |
| 管理者 | サービスを運営する側 | 運営チーム |

### 優先度（MoSCoW）

- **Must**: 「手軽な共有ページ」という核に直結する必須機能
- **Should**: 価値を高めるが核ではない機能
- **Could**: あると望ましい補助的機能

> **受け入れ条件の正本（SSoT）**: 各ストーリーの詳細な受け入れ条件・ビジネスルールは `docs/service/features/` を正本とする。
> 本ドキュメントにはストーリーレベルの要約のみを記載する。矛盾時は features/ を優先すること。

## EP-01 アカウント管理

| ID | ストーリー | 優先度 |
| --- | --- | --- |
| US-0101 | **利用者として**、メールアドレスとパスワードで会員登録したい。なぜなら自分専用のプロフィールを持つ起点になるから。 | Must |
| US-0102 | **利用者として**、登録済みアカウントでログイン・ログアウトしたい。なぜなら自分のプロフィールを安全に管理したいから。 | Must |
| US-0103 | **利用者として**、パスワードを変更・リセットしたい。なぜならパスワードを忘れても締め出されたくないから。 | Must |
| US-0104 | **利用者として**、アカウント情報（メールアドレス等）を編集したい。なぜなら登録情報は変わることがあるから。 | Should |
| US-0105 | **利用者として**、アカウントを削除（退会）したい。なぜなら利用をやめる時に自分のデータを残したくないから。 | Should |
| US-0106 | **利用者として**、WebAuthn（パスキー）を登録・管理してログインに使いたい。なぜならパスワードより安全・手軽に本人確認したいから。 | Should |

## EP-02 プロフィール編集

| ID | ストーリー | 優先度 |
| --- | --- | --- |
| US-0201 | **利用者として**、アイコン画像をアップロード・変更したい。なぜなら一目で自分だと分かるページにしたいから。 | Must |
| US-0202 | **利用者として**、ファースト・ラストネームを登録したい。なぜなら複合姓を含む自分の名前を正しく見せたいから。 | Must |
| US-0203 | **利用者として**、職業・職種を登録したい。なぜなら閲覧者に何をしている人か一目で伝えたいから。 | Must |
| US-0204 | **利用者として**、自己紹介文を入力したい。なぜなら肩書きだけでは伝わらない人柄や活動を補足したいから。 | Should |
| US-0205 | **利用者として**、SNS アカウントリンク（X・GitHub・LinkedIn 等）を登録したい。なぜなら散らばった活動先を 1 ページに集約したいから。 | Must |
| US-0206 | **利用者として**、入力中でも完成イメージを確認しながら編集したい。なぜなら公開前に見た目を確かめたいから。 | Could |

> アイコン画像は不適切画像の自動検出・ブロックの対象となる（EP-06 / 管理者機能と連動）。

## EP-03 公開・共有

| ID | ストーリー | 優先度 |
| --- | --- | --- |
| US-0301 | **利用者として**、固有 URL で自分のプロフィールページを公開したい。なぜなら 1 つのリンクをどこにでも貼って渡したいから。 | Must |
| US-0302 | **利用者として**、プロフィールの公開・非公開を切り替えたい。なぜなら見せたい時だけ見せたいから。 | Must |
| US-0303 | **利用者として**、固有 URL を SNS bio・名刺・署名・QR などに置いて共有したい。なぜなら初対面の相手に手早く自己紹介したいから。 | Must |
| US-0304 | **利用者として**、共有時にリンク先のプレビュー（OGP 等）が整って表示されてほしい。なぜなら渡した相手に良い第一印象を与えたいから。 | Should |

## EP-04 閲覧・検索

| ID | ストーリー | 優先度 |
| --- | --- | --- |
| US-0401 | **閲覧者として**、共有された固有 URL を、ログイン不要でそのまま開きたい。なぜなら相手の情報をすぐ確認したいから。 | Must |
| US-0402 | **閲覧者として**、プロフィールから各 SNS リンクへ遷移したい。なぜなら相手の活動先や連絡手段にたどり着きたいから。 | Must |
| US-0403 | **閲覧者として**、公開プロフィールの一覧を見たい。なぜなら気になる人や候補を探したいから。 | Should |
| US-0404 | **閲覧者として**、名前・職業・自己紹介でプロフィールを絞り込み検索したい。なぜなら目的に合う人を素早く見つけたいから。 | Should |

## EP-05 公開 API

| ID | ストーリー | 優先度 |
| --- | --- | --- |
| US-0501 | **開発者として**、API キーをスコープ（`read`/`full`）付きで発行・管理したい。なぜなら公開 API を最小権限で安全に利用したいから。 | Should |
| US-0502 | **開発者として**、公開 API で自分のプロフィールを取得（Read）したい。なぜなら自作サイトやアプリに反映したいから。 | Should |
| US-0503 | **開発者として**、公開 API でプロフィールを作成・更新・削除（CUD）したい。なぜなら画面を開かずにプログラムから一元管理したいから。 | Should |
| US-0504 | **開発者として**、レート制限の存在と上限を把握したい。なぜなら制限内で安定して API を使いたいから。 | Should |

> 公開 API には 1 分あたりのリクエスト数制限（Rate Limit）が設けられる。詳細仕様は `docs/service/features/` を正本とする。

| --- | --- | --- |
| US-0601 | **利用者として**、アップロードしたアイコンが不適切でないか自動でチェックされてほしい。なぜなら安心して使える場であってほしいから。 | Must |
