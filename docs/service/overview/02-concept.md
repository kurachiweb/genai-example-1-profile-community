# コンセプト — GenAI Profile Community

> サービス概要は [01-overview.md](./01-overview.md)、想定ユーザーは [03-target-users.md](./03-target-users.md) を参照。
> 本ドキュメントは「なぜ作るのか・どんな思想で作るのか」を記述する。

## ビジョン

**クリエイターの「はじめまして」を、一枚で完結させる。**

クリエイターやフリーランスにとって、最初の自己紹介は仕事の入り口だ。
しかし活動の情報は X・Instagram・GitHub・ポートフォリオ・連絡先などに散らばり、相手に「どこを見ればいいか」を毎回説明している。
GenAI Profile Community は、その散らばりを 1 つの固有 URL に束ね、誰に対しても同じページを差し出せる状態を当たり前にする。

## ミッション

- プロフィールを **最短数分で作れる** こと
- 作ったページを **どこにでも貼れる・誰にでも渡せる** こと
- 受け取った相手が **ログイン不要で一目で理解できる** こと

この 3 点を、専門知識のないユーザーでも達成できるようにする。

## コンセプトステートメント

> **「リンクを集約した、手軽な共有ページ。」**

本サービスは多機能な SNS でもポートフォリオ CMS でもない。
「自己紹介とリンクを、速く・きれいに・安全にまとめて渡す」という一点に価値を集中させる。

## 核となる価値 ─ 3 つの「速さ」

コンセプトの核は **手軽さ＝速さ** である。すべての設計判断は、この 3 つの速さを損なわないかで評価する。

### 1. 作るのが速い（Time to First Profile）

- 会員登録 → 名前・職業・リンクを入力 → 公開、までを迷わせない。
- 入力項目は「自己紹介に本当に要るもの」に絞る。装飾や設定でユーザーを止めない。
- 初期状態でも見栄えのするページになる（デザイン作業を不要にする）。

### 2. 渡すのが速い（Shareability）

- 1 ユーザー = 1 固有 URL。覚えやすく、貼りやすく、QR にもしやすい。
- SNS bio・名刺・メール署名・DM など、あらゆる導線に置ける軽さ。
- 公開 API により、自作サイトやアプリにも同じプロフィールを差し込める。

### 3. 見るのが速い（Glanceability）

- 受け取った相手はログイン不要で、名前・肩書き・リンクを一目で把握できる。
- アイコン・名前・職業・リンクという視線の流れを崩さない情報設計。
- 名前は柔軟に（ミドルネーム対応）、けれど表示は常に整って見える。

## デザイン原則

プロデューサー・デザイナー・エンジニアが判断に迷ったとき立ち返る原則。

1. **手軽さを最優先する。** 機能を足す前に「3 つの速さ」を損なわないか問う。迷ったら載せない。
2. **デフォルトで完成する。** 設定やカスタマイズを前提にしない。空欄でも成立するページにする。
3. **名前に敬意を払う。** ミドルネームや多様な表記を正しく扱い、誰の名前も崩さない。
4. **健全さは前提条件。** 不適切画像の自動検出、通報、凍結を運営の土台として組み込む。
5. **渡しやすさを設計に織り込む。** URL・OGP・QR など「共有される瞬間」を一級の体験として扱う。
6. **API も一級の入り口。** 画面と公開 API は対等。どちらからでも同じことができる。

## 差別化ポイント

| 観点 | GenAI Profile Community | 一般的な SNS / ポートフォリオ CMS |
| --- | --- | --- |
| 主目的 | 自己紹介とリンクの集約・共有 | 交流・投稿、または作品ホスティング |
| 作成コスト | 数分・知識不要 | 継続運用や制作作業が必要 |
| 受け手の負担 | ログイン不要・一目で把握 | アカウントや読み込みが要ることも |
| 名前表現 | ミドルネーム対応の柔軟な氏名 | 単一表示名が中心 |
| 機械可読性 | 公開 API で取得・更新が可能 | API 非公開、または交流向け |
| 健全性 | 自動検出・通報・凍結を標準装備 | サービス依存 |

> 「手軽な共有ページ」という核を守るため、交流機能・課金・本格 CMS には**あえて踏み込まない**。スコープは [01-overview.md](./01-overview.md) を参照。

## なぜ今このサービスか

- クリエイター/フリーランスの活動情報は複数プラットフォームに分散し、「まとめページ」需要が定着している。
- 一方で、凝ったサイトを作る・維持するコストは活動の本筋ではない。
- 「速く作れて・速く渡せて・速く伝わる」一枚があれば十分、というニーズに、本サービスは正面から応える。

## トーン & マナー

- **親しみやすく、軽い。** 専門用語で身構えさせない。
- **整っていて、信頼できる。** 手軽でも雑には見せない。受け取った相手に安心感を与える。
- **クリエイターを主役にする。** サービスの個性より、ユーザーのアイコン・名前・リンクを引き立てる。

## 注記（このドキュメントの前提）

本サービスは GenAI 活用開発のサンプル/デモを前提とする。
そのため本ドキュメントでは収益モデル・事業 KPI・成長戦略は扱わず、**サービスとして何を価値とするか**の記述に集中している。
