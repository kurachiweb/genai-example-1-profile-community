# サービス概要ドキュメント索引

「GenAI Profile Community」のサービス像を、企画・コンセプト・ターゲット・ユーザーストーリーの観点から記述したドキュメント群。
プロデューサー・デザイナー・エンジニア・新規参加者が「このサービスは何を、誰のために、なぜ作るのか」を最初に理解するための入り口とする。

> **位置づけ**: 本サービスは GenAI 活用開発のサンプル/デモを前提とする。収益モデルや事業 KPI は本ドキュメント群の対象外とし、サービス像とユーザー価値の記述に集中する。

## このディレクトリのドキュメント

| ファイル | 内容 | 主な読者 |
| --- | --- | --- |
| [01-overview.md](./01-overview.md) | サービス概要。何を提供するか、主要機能、利用シーン、スコープ | 全員（まず最初に読む） |
| [02-concept.md](./02-concept.md) | コンセプト。ビジョン・提供価値の核・デザイン原則・差別化ポイント | プロデューサー、デザイナー |
| [03-target-users.md](./03-target-users.md) | どのユーザーがこのサービスを必要とするか。ターゲット像とペルソナ、解決する課題 | プロデューサー、デザイナー、企画 |
| [04-user-stories.md](./04-user-stories.md) | ユーザーストーリー。利用者・閲覧者・管理者の「〜したい」を機能群（エピック）別に整理 | エンジニア、QA、企画 |

## 読む順番（推奨）

```
01-overview.md  →  02-concept.md  →  03-target-users.md  →  04-user-stories.md
（全体像）          （なぜ・思想）       （誰のために）           （何を作るか）
```
